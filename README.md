# Comp248: AI System Design | Final Project: 
Design and prototype a multi-agent agentic system with search and summarization capabilities.
Our project focuses on developing a Multi-agent AI System for Beauty Product Research and Summarization. The application uses Retrieval Augmented Generation (RAG) to retrieve relevant information and generate informative, context-aware responses to beauty product-related inquiries. 
The system integrates Python, LangChain, LangGraph, ChromaDB, and Streamlit to support document retrieval, multi-agent coordination, and AI powered summarization. Each component contributes to the overall workflow, allowing specialized agents to collaborate in researching and presenting relevant information.
